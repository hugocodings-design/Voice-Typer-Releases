# Voice Typer — téléchargements

Voice Typer est une application de dictée vocale pour Windows qui fonctionne **entièrement sur votre PC** :
la reconnaissance vocale et l'IA d'écriture tournent en local, rien n'est envoyé sur Internet.

## Installer

Téléchargez `VoiceTyperSetup-x.y.z.exe` dans la [dernière version](../../releases/latest) et lancez-le.
Aucun droit administrateur n'est nécessaire.

## Mises à jour

Voice Typer vérifie lui-même s'il existe une nouvelle version et propose de l'installer.
Vos réglages, votre historique et vos modèles sont conservés.

Ce dépôt ne contient que les installateurs ; le code source n'est pas public.
